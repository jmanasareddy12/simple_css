🎨 Simple CSS Programs Collection

A collection of basic CSS projects and animations created to practice core CSS concepts such as styling, positioning, transitions, and animations.
This repository demonstrates how powerful CSS can be in creating interactive visual effects without using JavaScript.

The projects focus on learning-by-building small visual components and animations using pure HTML and CSS.

📌 Projects Included
🎨 Color Changing Background

A simple animation that continuously changes the background color using CSS @keyframes.

Concepts Used

CSS animations

Keyframes

Background transitions

Timing functions

🏀 Bouncing Ball Animation

A ball animation that simulates bouncing motion using CSS transforms and animation timing.

Concepts Used

transform: translateY()

Animation timing

Infinite animation loops

Positioning

🏅 Olympic Rings

Recreation of the Olympic rings using CSS shapes and positioning.

Concepts Used

Borders and circular shapes

Absolute positioning

Layout alignment

CSS styling techniques

🕒 CSS Clock

An analog clock created using CSS animations to rotate hour, minute, and second hands.

Concepts Used

Rotation using transform: rotate()

Animation delays

Transform origin

Real-time visual simulation

🛠️ Technologies Used

HTML5

CSS3

CSS Animations

Flexbox & Positioning
